PadBuddy

A fast, native macOS app for your CoderPad pads and questions — from the menu bar or a full window, without opening a browser tab. And it talks to your AI assistant.

Lives in your menu bar, on your desktop as a widget, and in Control Center.

Direct download .dmg, auto-updates via Sparkle Coming soon to the Mac App Store View on GitHub

Free. Requires macOS 15 or later, an existing CoderPad account, and your own API key. Not affiliated with, or endorsed by, CoderPad, Inc.

Built-in MCP server

Talk to your interviews

Ask AI assistants — Claude Desktop, Claude Code, Codex, or any MCP client — about your CoderPad pads, questions, quota, and organization in plain language. No copy-pasting JSON between tabs.

The app is the server

Nothing extra to build, download, or run. PadBuddy serves the Model Context Protocol itself with PadBuddy --mcp, reading your API key straight from the macOS Keychain.

Read-only by design

The server only reads your selected account. It can browse and summarize your pads and questions; it never creates, edits, or deletes interview content.

Copy-paste setup

The app's MCP Server settings pane gives you the exact configuration for your client — copy it, paste it, done.

Example client configuration

{
  "mcpServers": {
    "padbuddy": {
      "command": "/Applications/PadBuddy.app/Contents/MacOS/PadBuddy",
      "args": ["--mcp"]
    }
  }
}

The exact command for your client is copy-pasteable from the app's MCP Server settings pane.

Everything else, native

  • Pads at a glance. Browse every pad with fast search and filters for state, language, owner, team, type, and date — cached so the app opens instantly.
  • Pad detail. Read the code with syntax highlighting (single- and multi-file), step through the session event timeline, and see the whiteboard, notes, and participants.
  • Questions. Browse and search your question bank, star favorites for one-click new pads, and create or edit questions inline.
  • Create & manage. Start a new pad, seed it from a question, edit details, end an interview, or delete a pad — all from the app.
  • Menu bar app. Create a pad or jump to a recent one straight from the menu bar, and find your pads from Spotlight.
  • Widget. Keep your recent pads on the desktop or in Notification Center, one click from opening them.
  • Control Center. A New Pad button right in Control Center, so a fresh interview is always a click away.
  • Notifications & Dock badge. Know when a pad changes without keeping the window open.
  • Multiple accounts. Switch between CoderPad accounts, including self-hosted or regional deployments.
  • Screen support. Browse your CoderPad Screen campaigns and test sessions alongside your interview pads.
  • Liquid Glass design. A modern Mac app that feels at home on macOS Tahoe, with a clean Mail-style sidebar.

How updates work

PadBuddy updates itself in place. The Mac App Store build aside, the direct download is a signed, notarized .dmg that checks for new versions and installs them with one click — no reinstalling by hand.

Requirements

  • macOS 15 or later.
  • An existing CoderPad account and a CoderPad API key (get one here).

Privacy

Your API key is stored only in the local macOS Keychain and is used solely to talk to CoderPad's own API. The app collects no analytics, shows no ads, and has no developer-operated server. Pad code and transcripts stay on your Mac — and when you connect the MCP server, they're shared only with the AI assistant you point at it. See the privacy policy for details.
